1
🌐

Client Request

React / Android sends HTTP POST to /api/v1/generate with the prompt, quality mode, resolution (512 or 768), and optional seed. Server validates resolution and prompt length (≤ 1000 chars).

FastAPI · Pydantic
2
🔒

Single-Flight Guard

A non-blocking mutex (threading.Lock) serialises GPU work. Concurrent requests instantly receive HTTP 429 (Busy). Prevents multi-job CUDA OOM collisions on the 8 GB laptop GPU.

Python threading · FastAPI
3
🔤

Semantic NLP Analysis

Pure-Python rule-based parser extracts: objects ("hat", "log"), spatial relations ("resting on" → on_top), attributes ("vintage leather", "mossy"), lighting ("golden hour"). Runs in < 0.8 ms, zero VRAM.

ai_engine/prompt/parser.py
4
🎛️

Adaptive Controller

Reads live GPU budget (VRAM). Scores benchmarked profile entries. Selects the best-fitting config. If preferred config is unsafe, walks the 4-rung fallback ladder: Resolution → Precision → Steps → Model. Fully deterministic — same inputs always yield same decision.

ai_engine/adaptive/controller.py
5
🔄

GPU Lease & Model Load

Evicts any dormant pipeline from VRAM (pipe.to("cpu") + torch.cuda.empty_cache()). Loads the selected model in FP16. The model is cached after first load — subsequent requests skip the 3-6 s load step entirely.

backend/app/services/multi_model.py
6
📝

CLIP Text Encoding

The raw prompt is tokenised (BPE, 77 tokens) and encoded by the frozen CLIP ViT-L/14 text encoder into a tensor of shape (1, 77, 768). SD-Turbo uses CFG = 0.0 so only the conditional pass runs — 50% fewer UNet evaluations than SD 1.5's CFG = 7.5.

CLIP ViT-L/14 · diffusers
7
🌀

Latent Denoising (UNet)

A seed-fixed Gaussian noise tensor (1, 4, 64, 64) is denoised in latent space via EulerDiscreteScheduler (SD-Turbo) or LCMScheduler. Each step: cross-attention with text embeddings steers structure. 1-2 steps for Turbo; 4-8 steps for LCM-LoRA.

Time-conditioned UNet · Cross-attention
8
🖼️

VAE Decoding

The 64×64×4 latent is decoded to a full-resolution 512×512×3 RGB image. Standard AutoencoderKL takes ~52 ms. Optional TAESD (1.8M params, distilled) decodes in ~18 ms — 65% faster — cutting end-to-end to 340 ms.

AutoencoderKL / TAESD
9
🔬

CV Quality Gate

Classical CV measures sharpness (Laplacian), noise (Immerkaer MAD), brightness, contrast, halo/ringing (Sobel plateau). 38% of images are clean and bypass correction entirely (dead-band). "Golden hour" prompt intent suppresses the warm colour-cast alarm.

computer_vision/pipeline.py

📐 Classical CV Image Enhancement Pipeline

1

No-Reference Quality Assessment

Measures 13 objective pixel metrics: Laplacian variance, Crete re-blur ratio, Immerkaer noise σ, luminance mean/std, Gray-World color deviation, and Sobel edge halo ringing.

2

Dead-band Gate (38% Bypass)

Images falling inside conservative tolerance thresholds skip filtering entirely, protecting visual fidelity and reducing compute overhead to ~18 ms.

3

Guarded Auto-Enhancement

Runs conservative corrections only on flagged defects: Gray-world white balance (color cast), logarithmic gamma (exposure), and mild CLAHE on lightness (contrast).

4

Edge-Aware Smoothing & Sharpening

Bilateral filtering suppresses high-frequency noise without blurring edges. Edge-preserving unsharp masking restores fine surface textures.

Adversarial Diffusion Distillation combines score distillation (from SD 2.1 teacher) with a discriminator adversarial loss to enable 1-step inference with sharp, coherent outputs. No CFG needed → single UNet pass per step.

Consistency Distillation · Balanced Mode
Consistency distillation trains a function f(z_t, t) = z_0 mapping any PF-ODE trajectory point directly to the clean origin. LoRA rank-decomposition injects adapter weights into cross-attention layers without retraining the full 860M UNet.

TAESD
Tiny Autoencoder · VAE Accelerator
Tiny AutoEncoder for Stable Diffusion replaces the 83.7M parameter AutoencoderKL with a 1.8M parameter distilled convolutional decoder. Drops VAE decode from 52 ms to 18 ms (65% faster). Pairs with LCM-LoRA to reach 340 ms total.

Object Detection · Best-of-N Verifier
Generate N candidates with SD-Turbo, let DETR (Facebook ResNet-50 detector) select the best by detecting required objects and colours, then have OWL-ViT (Google open-vocabulary detector) independently verify — grading by a different model prevents self-grading.

🛣️ Key API Endpoints

POST /api/v1/generate

Main generation endpoint. Body: prompt, quality_mode, resolution, seed. Returns: image_url, generation info, performance telemetry, quality metrics.

POST /api/v1/inpaint

Mask-guided inpainting. Accepts source image + binary mask + prompt. Areas outside mask stay pixel-perfect identical.

GET /api/v1/adapter/status

Returns the adapter state: configured, active, adapter SHA-256 hash, base revision. Never exposes paths or secrets.

POST /api/v1/chat

Floating assistant. Routes to Groq LLM with conversation memory. API key stored server-side — never sent to browser.

POST /api/v1/transcribe

Audio → text via Groq Whisper. 24 languages. Used by the voice-to-prompt feature.

GET /images/{id}.png

Serves generated images. Requires signed-in session — gallery images are not publicly accessible by default.

Implementation Status & Limitations

We kept every negative result. Good engineering requires honesty about what works, what partially works, and what is planned.

✅ Implementation Status

⚠️ Honest Negative Results

🐛 LoRA Scale Bug (Found & Fixed)

First distillation run used alpha=64 while public adapter uses alpha=8. 8× too strong → FID 253 (garbage output). Root cause documented in evaluation/reports/distillation_scale_bug.md. Guard added to trainer to prevent recurrence.

🐢 INT8 Quantization Was Slower

PyTorch dynamic INT8 quantization: 495 ms vs 451 ms (FP16). Without dedicated TensorRT INT8 GEMM kernels, dequantize overhead on memory bandwidth outweighs weight size savings. Documented and left off by default.

🎓 Project LoRA Ties Public, Doesn't Beat It

Custom trained LCM-LoRA (500 COCO steps): FID 120.4. Public adapter: FID 121.2. Difference is within noise (KID 0.010 ± 0.003 for both). Longer training (500 → 2000 steps) drifted slightly worse.

🔬 Classical CV Barely Moves FID/CLIP

Mean CLIP Δ = −0.0009 (CV on vs off). SD-Turbo output is already clean — the CV quality gate rarely finds correctable issues. Functions as a safety net, not an enhancer. 38% of images bypass correction in the dead-band.
