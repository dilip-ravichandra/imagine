Team & Problem Statement

  • Problem Statement: ProbID - P3: Resource-Efficient Text-to-Image Generation for Mobile Devices
  • Student USNs: 1MS22CS001, 1MS22CS002
  • Repository Architecture: Hybrid Client-Server (FastAPI GPU backend + Modern Web Dashboard + Android Client)
  • Frozen API Contract: REST v1.0.0 (/api/v1/generate, /api/v1/capabilities, /api/v1/model)

Viva / Demo Highlights

1. 3.01× Empirical Speedup: Reducing denoising steps from 4 to 2 and running native fp16 cut median end-to-end latency from 866 ms to 288 ms.
2. VRAM Conservation (-43.4%): Peak GPU memory dropped from 6,500 MB to 3,678 MB, staying safely within 8 GB laptop GPUs.
3. Hybrid Architecture Justification: Local mobile diffusion crashes mobile OS limits (>3.5 GB RAM). A hybrid architecture allows mobile phones to stream generation in <300 ms over LAN/Wi-Fi.
